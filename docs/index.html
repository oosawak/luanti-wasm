WebAssembly Emscripten C++17 SDL2 WebGL
▶ ブラウザで起動する

プロジェクト概要

このプロジェクトは、オープンソースのボクセルゲームエンジン Luanti (旧称 Minetest) の C++ クライアントを Emscripten を使って WebAssembly にコンパイルし、 インストール不要でブラウザ上で動かすことを目的としています。


This project compiles the Luanti (formerly Minetest) C++ game client to WebAssembly via Emscripten, enabling it to run directly in the browser without any installation.

技術スタック

🔧 ビルドツール

Emscripten 5.0.7 + CMake 3.28
emcmake / emmake でクロスコンパイル

🎮 グラフィックス

IrrlichtMt → WebGL 変換
SDL2 (Emscripten ポート) でウィンドウ管理

📦 依存ライブラリ

zlib / libpng / libjpeg / freetype / sqlite3 / zstd
すべて Emscripten sysroot でビルド

⚡ 実行環境

ASYNCIFY=1 で非同期対応
初期メモリ 512MB / 最大 2GB

機能ステータス

機能状態備考
レンダリング (WebGL)✓ 有効IrrlichtMt → WebGL
SDL2 入力✓ 有効キーボード・マウス
SQLite3✓ 有効ローカルDB
PNG / JPEG / Freetype✓ 有効テクスチャ・フォント
サウンド (OpenAL)✗ 無効将来対応予定
ネットワーク (cURL)✗ 無効Fetch API で代替予定
マルチスレッド△ 限定的SharedArrayBuffer 要設定
サーバー✗ 無効クライアントのみ

ビルド方法

必要なもの

• Emscripten SDK (emsdk)
• CMake 3.28+
• Python 3, Node.js, Git 

# emsdk インストール
bash emscripten/install-emsdk.sh

# ビルド実行
bash emscripten/build.sh
